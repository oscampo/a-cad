# 12. Atajos de teclado

Las teclas de cada herramienta, para trabajar con teclado.

V seleccionar, P punto, L línea, K línea constructiva, C círculo, B rectángulo, G polígono, F redondeo, O elipse, Ctrl/Cmd+C copiar, Ctrl/Cmd+V pegar, R arco por centro, A arco por 3 puntos, S spline, T texto, D acotar, I intersección, X recortar, E extender. Ctrl/Cmd+Z deshacer, Ctrl/Cmd+Y (o Ctrl/Cmd+Mayús+Z) rehacer, Supr o Retroceso borra, Esc cancela o termina.
